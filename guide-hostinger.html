Guide de déploiement Hostinger

Guide étape par étape pour mettre en ligne le site Media Agency sur Hostinger — connexion du domaine, upload des fichiers, SSL, et vérification.

Table des matières

  1. Préparer les fichiers à uploader
  2. Créer l'hébergement sur Hostinger
  3. Connecter votre domaine
  4. Uploader les fichiers via le File Manager
  5. Activer le certificat SSL
  6. Vérifier le site en ligne
  7. Modifier le contenu du site
  8. Configurer les emails (optionnel)
1
Préparer les fichiers à uploader

Avant d'uploader, assurez-vous que le dossier du site contient bien ces fichiers et dossiers :

📁 css/    ├── styles.css    └── extras.css 📁 js/    └── main.js 📁 blog/    ├── roi-google-ads-2025.html    ├── erreurs-paid-ads.html    └── [... 8 autres articles] 📄 index.html 📄 services.html 📄 about.html 📄 pourquoi-nous.html 📄 contact.html 📄 merci.html 📄 faq.html 📄 blog.html 📄 mentions-legales.html 📄 politique-confidentialite.html

Créez un fichier ZIP de tout le dossier pour un upload plus rapide. Sur Windows : clic droit → "Compresser dans un fichier ZIP".

2
Créer l'hébergement sur Hostinger
  1. Connectez-vous à votre compte Hostinger (hostinger.com)
  2. Dans le dashboard, cliquez sur Hosting puis Add Website
  3. Choisissez le plan Premium Web Hosting (recommandé pour un site vitrine professionnel)
  4. Sélectionnez la période (12 ou 24 mois pour le meilleur tarif)
  5. À la création, choisissez "I have an existing domain" si vous avez déjà un domaine, ou "Register a new domain"

Hostinger inclut souvent un nom de domaine gratuit la première année avec les plans Premium et Business.

3
Connecter votre domaine

Si votre domaine est chez Hostinger : il est automatiquement connecté. Passez à l'étape 4.

Si votre domaine est chez un autre registrar (OVH, GoDaddy, etc.) :

  1. Dans le panel Hostinger, allez dans Hosting → Manage → DNS Zone
  2. Notez les nameservers Hostinger : ns1.dns-parking.com et ns2.dns-parking.com
  3. Connectez-vous à votre registrar et modifiez les nameservers de votre domaine pour les remplacer par ceux d'Hostinger
  4. Attendez 24 à 48 heures pour la propagation DNS

La propagation DNS peut prendre jusqu'à 48h. Votre site peut être temporairement inaccessible pendant cette période — c'est normal.

4
Uploader les fichiers via File Manager
  1. Dans le panel Hostinger, allez dans Hosting → Manage → File Manager
  2. Naviguez dans le dossier public_html (c'est la racine de votre site)
  3. Supprimez les fichiers par défaut s'il y en a (ex: index.html de bienvenue Hostinger)
  4. Cliquez sur Upload Files → sélectionnez votre ZIP
  5. Une fois uploadé, faites un clic droit sur le ZIP → Extract
  6. Assurez-vous que index.html est bien à la racine de public_html (pas dans un sous-dossier)

Alternative via FTP : utilisez FileZilla avec vos identifiants FTP Hostinger (disponibles dans Hosting → Manage → FTP Accounts).

Structure finale dans public_html :

public_html/    ├── index.html ← doit être ici directement    ├── css/    ├── js/    ├── blog/    └── [autres fichiers .html]
5
Activer le certificat SSL (HTTPS)
  1. Dans le panel Hostinger, allez dans Hosting → Manage → SSL
  2. Cliquez sur Install SSL pour votre domaine
  3. Hostinger fournit un certificat Let's Encrypt gratuit — activez-le
  4. Activez la redirection HTTP → HTTPS automatique dans les paramètres SSL

L'activation SSL peut prendre 10 à 30 minutes. Une fois actif, votre site sera accessible en https://votredomaine.fr avec le cadenas vert.

Sans SSL, Google Chrome affiche un avertissement "Non sécurisé" qui fait fuir les visiteurs et pénalise votre référencement. Ne sautez pas cette étape.

6
Vérifier le site en ligne

Une fois les fichiers uploadés et le SSL activé, vérifiez ces points :

  • ✓ https://votredomaine.fr charge correctement
  • ✓ Le style (fond noir, texte blanc, vert) s'affiche correctement
  • ✓ Toutes les pages sont accessibles (services.html, about.html, etc.)
  • ✓ Le formulaire de contact redirige vers merci.html
  • ✓ Les articles de blog s'affichent
  • ✓ Le site est responsive sur mobile (testez depuis votre téléphone)
  • ✓ Le cadenas HTTPS est présent dans la barre d'adresse

Testez la vitesse de chargement avec Google PageSpeed Insights. Le site statique HTML/CSS/JS devrait obtenir un score 90+ sans optimisation supplémentaire.

7
Modifier le contenu du site

Pour modifier le contenu du site sans retoucher le code :

Changer un texte :

  1. Ouvrez le fichier .html correspondant dans File Manager (Hostinger) ou dans votre éditeur local (VS Code)
  2. Trouvez le texte avec Ctrl+F
  3. Modifiez directement le texte entre les balises HTML
  4. Sauvegardez et re-uploadez le fichier (ou sauvegardez directement dans File Manager)

Changer les couleurs / polices :

Toutes les couleurs et polices sont dans css/styles.css sous les variables CSS en haut du fichier (section :root). Changez par exemple --green: #7ED955 pour modifier la couleur principale.

Ajouter un article de blog :

  1. Dupliquez un fichier article existant (ex: blog/meta-ads-vs-google-ads.html)
  2. Renommez-le (ex: blog/mon-nouvel-article.html)
  3. Modifiez le contenu : titre, meta description, contenu de l'article
  4. Ajoutez une carte vers cet article dans blog.html

Changer les tarifs :

Ouvrez index.html et cherchez la section avec id="pricing". Les prix sont directement dans le HTML.

8
Configurer les emails professionnels (optionnel)

Hostinger Premium inclut des adresses email professionnelles (contact@votredomaine.fr).

  1. Dans le panel Hostinger → Emails → Manage
  2. Créez l'adresse contact@votredomaine.fr
  3. Configurez une redirection vers votre Gmail personnel pour recevoir les emails dans votre boîte habituelle
  4. Pour utiliser cette adresse dans le backend Node.js, mettez à jour le fichier backend/.env avec :
    SMTP_HOST=smtp.hostinger.com
    SMTP_USER=contact@votredomaine.fr
    SMTP_PASS=votremotdepasse

Pour un site statique sans backend Node.js, le formulaire redirige directement vers merci.html. Le backend est optionnel — il permet en plus d'envoyer un email automatique.
